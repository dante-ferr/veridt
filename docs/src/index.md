# Veridt

Livro de método do Veridt. Descreve o que já foi decidido, a arquitetura que o código deve seguir e o trabalho ainda aberto. O enunciado do produto permanece no repositório de arquitetura. Este livro não o reproduz.

O plano de trabalho dos agentes está em `AGENTS.md`, na raiz do repositório.

## Como ler

| Capítulo | O que explica |
| :--- | :--- |
| [Decisões registradas](decisoes.md) | O que já vale e o que ainda precisa do desenvolvedor |
| [Mapa da arquitetura](arquitetura.md) | Onde o código vai morar e o que reaproveitar do sketch |
| [SOLID](solid.md) | Sugestões e decisões sobre a estrutura do código |
| [Roteiro](roadmap.md) | Trabalho aberto, limitado aos REQ 01 a 05 |

Pré-visualização local:

```bash
make docs-serve
```

Abre em `http://localhost:3000`. O livro é local. Não há publicação automática.
